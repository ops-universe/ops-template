# Ops project starter

Developer Preview · Node.js 22+ · MIT (proposed in this PR).

Run `npm ci`, `npm test`, `npm run demo`. The policy example derives risk from trusted configuration and does not execute actions. See [architecture](docs/architecture/overview.md), [threat model](docs/security/threat-model.md) and [website instructions](website-react/README.md). The website lockfile is committed and CI uses npm ci; product-specific routing, SEO prerendering and live deployment remain pending. ## Agent checkpoints

Generated repositories inherit CLAUDE.md and docs/status/IMPLEMENTATION-STATUS.md and RESUME.md. The starter explicitly marks product functionality and acceptance as unverified. Maintain exact commit-linked evidence as work progresses. The shared standards revision is pinned in CLAUDE.md; no external tool runs automatically.
